# Решения

Журнал решений, принятых при реализации `sweep`. Спека — источник истины
(`docs/sweep-spec.md`); всё, что в ней не описано и не покрыто её таблицей
«Открытые вопросы и решения по умолчанию», записывается здесь.

| Дата | Решение | Почему | Цена ошибки |
| --- | --- | --- | --- |
| 2026-10-17 | Модуль и репозиторий: `github.com/webcartel/sweep` | Репозиторий владельца уже создан на GitHub (пустой); в спеке стояла заглушка `github.com/<owner>/sweep` | Массовая замена импортов во всех пакетах |
| 2026-10-17 | Лицензия MIT, `Copyright (c) 2026 webcartel` | Решение по умолчанию из спеки | Смена лицензии после публикации правил сообщества |
| 2026-10-17 | Корень репозитория — каталог проекта (`Cleaner`), дерево из спеки — от него | В каталоге уже живут `AGENTS.md` и `docs/sweep-spec.md`; лишний уровень вложенности ничего не даёт | Имя каталога не совпадает с именем репозитория `sweep` — косметика |
| 2026-10-17 | README и код — по-английски, `docs/decisions.md` и спека — по-русски | Репозиторий публичный, в v1 интерфейс и имена правил английские; рабочие документы ведутся по-русски | Перевод README, если владелец захочет русский |
| 2026-10-17 | Версия по умолчанию `dev`, инжектится `-ldflags "-X github.com/webcartel/sweep/internal/cli.Version=..."` | Позволяет `goreleaser` проставлять версию, а тестам — свою | Правка одной строки в `.goreleaser.yml` на этапе релиза |
| 2026-10-17 | Файла `.golangci.yml` на этапе 0 нет: CI использует набор линтеров по умолчанию | Полный набор линтеров спеки — вопрос этапа 1+, когда появится код, который стоит ограничивать | Сначала ослабленный линт: пропущенные замечания появятся позже |
| 2026-10-17 | `sweep` без аргументов печатает справку, а не открывает TUI | TUI — этап 5; справка честнее заглушки | Поведение изменится на этапе 5 — это и есть план спеки |
| 2026-10-17 | `schema/rule.schema.json`, содержимое `rules/*`, fuzz-прогон и релиз через `goreleaser` в этап 0 не входят | Спека относит их к этапам 1, 6 и к разделу «Тестирование и CI» в целом | Ничего: критерий «Этап 0» из спеки выполнен полностью |
| 2026-10-17 | Каталоги `rules/{browsers,system,dev,apps}`, `schema`, `testdata` держатся в git через `.gitkeep` | Пустые каталоги git не хранит, а структура из спеки должна быть видна | Ничего |
