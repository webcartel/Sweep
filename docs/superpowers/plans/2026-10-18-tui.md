# План этапа 5 — TUI (Bubble Tea)

Каждая задача: TDD (red → green), `gofmt`, `go vet ./...`, `golangci-lint run` чисто, мелкий коммит.
Источник истины — `docs/sweep-spec.md`, раздел TUI (строки ~438–484). Всё, чего спека не называет, — ruling в `docs/decisions.md` («Решения этапа 5»).

## Решения (утверждены пользователем)
- Библиотека: **Bubble Tea** + **Bubbles** (table/list) + **Lip Gloss** — новая зависимость, причина в decisions.
- Мышь включена; при старте — экран выбора профиля, Enter запускает скан; чистка по модалке подтверждения; правки конфига в TUI нет.
- Главный экран = один экран: шапка (профиль, правила/файлы/байты), таблица правил, статусная строка с хоткеями; подтверждение — модалка; выполнение — прогресс по правилам + лента событий.
- Стиль: сдержанный, Lip Gloss-темы, цвет только смысловой (risk-метки, ошибки).

## Экраны (машина состояний `screen`)
`profile` → `scanning` → `list` (главный) → `detail` (pop-up по Enter) → `confirm` (модалка) → `running` → `done`. `?` — попап помощи, из любого экрана кроме running.

## Ruling-и для decisions.md (черновик)
- Зависимость: bubbletea/bubbles/lipgloss — единственный зрелый TUI-стек для Go, Model-Update-View из спеки.
- Сохранение отчёта `s`: файл рядом с логом, имя `sweep-report-YYYYMMDD-HHMMSS.json`.
- `q` во время running → confirm (не kill процесса чистки).
- Мышь: клик по строке — выбор, по чекбоксу — тумблер; скролл колесом в списках.
- Тумблер dangerous в списке разрешён, но запуск требует `yes` в модалке.
- Тема: цвет только для risk/ошибок, остальное — монохром + dim.
